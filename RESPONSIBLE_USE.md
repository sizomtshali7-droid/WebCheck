# Responsible use

Webcheck sends requests that look like those of an attacker looking for weaknesses. Using it on a website without permission may be illegal and can cause harm.

## Rules

1. **Only test what you own or have written permission to test.** Written permission should name the website, the dates, and what you may do.
2. **Use test accounts.** Never use real people's accounts or data.
3. **Start on your own computer.** Use the practice application first.
4. **Do not use it to cause damage.** The tool only reads and asks questions, but anything that slows or disrupts a live service is not allowed.
5. **Report what you find.** If you find a weakness on a system you were allowed to test, tell its owner clearly and privately, with the evidence from the report.
6. **Keep reports private.** A report lists weaknesses. Share it only with the owner and people who need it.

## Built-in protection

The tool refuses any target that is not on this computer unless `--i-have-permission` is added. That option is a promise that you have permission. Do not add it unless that is true.
